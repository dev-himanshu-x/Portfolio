# Himanshu Jaiswal — Portfolio

A high-fidelity, immersive portfolio built with modern web technologies.

## Tech Stack
- **Core**: React 19 + TypeScript
- **Runtime**: Bun
- **Build Tool**: Vite
- **Routing**: TanStack Router
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Styling**: Vanilla CSS with Design Tokens

## Features
- **Scratch Card Intro**: Interactive reveal effect using HTML5 Canvas.
- **Deep Sea Theme**: Immersive animations of bubbles, fish, and octopuses.
- **Responsive Design**: Pixel-perfect layout from mobile to desktop.
- **Smooth Scroll**: Integrated navigation with scroll-spy side menu.

## Getting Started

1. Install dependencies:
   ```bash
   bun install
   ```

2. Run development server:
   ```bash
   bun run dev
   ```

3. Build for production:
   ```bash
   bun run build
   ```
